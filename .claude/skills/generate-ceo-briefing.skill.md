# Generate CEO Briefing

Generate a comprehensive weekly business intelligence report analyzing revenue, expenses, completed tasks, bottlenecks, and providing proactive suggestions.

## Usage

This skill generates a CEO Briefing that includes:
- Revenue and expense summary from Odoo
- Completed tasks analysis
- Bottleneck identification
- Unused subscription detection
- Upcoming deadline alerts
- Proactive business optimization suggestions

The briefing is automatically generated every Monday at 8:00 AM, but can also be triggered manually.

## Prerequisites

- Odoo integration configured and working
- Business_Goals.md file with revenue targets and subscriptions
- Task files in vault (Done/, In_Progress/, etc.)
- At least one week of transaction data in Odoo

## Commands

### Generate Current Week Briefing

```
Generate the CEO Briefing for this week
```

**What happens:**
1. AI Employee analyzes past 7 days of data
2. Retrieves transactions from Odoo (invoices, payments, expenses)
3. Analyzes completed tasks from vault
4. Detects bottlenecks (tasks taking longer than expected)
5. Identifies unused subscriptions (not used in 30+ days)
6. Checks for upcoming deadlines (next 7 days)
7. Generates proactive suggestions
8. Creates markdown briefing file in CEO_Briefings/

### Generate Briefing for Specific Week

```
Generate the CEO Briefing for the week of [date]
```

**Example:**
```
Generate the CEO Briefing for the week of February 3, 2026
```

### 💡 Proactive Suggestions

**Unused Subscriptions:**
- Services not used in 30+ days

**Upcoming Deadlines:**
- High-priority deadlines in next 7 days

- Action required alerts

**Revenue Optimization:**
- Suggestions to increase average invoice value
- Upselling opportunities
- Process improvements

### 📅 Upcoming Deadlines

- All deadlines within next 7 days

## Automatic Scheduling

The CEO Briefing is automatically generated every Monday at 8:00 AM. No manual intervention required.

**Schedule:**
- **Day**: Every Monday
- **Time**: 8:00 AM (local timezone)
- **Location**: `AI_Employee_Vault/CEO_Briefings/YYYY-MM-DD_Monday_Briefing.md`

## Troubleshooting

### "No transaction data available"
- Ensure Odoo integration is working
- Check that transactions exist for the past 7 days
- Verify Odoo MCP server is running: `http://localhost:3100/health`
- Test Odoo connection: `python -c "from services.odoo_service import OdooService; OdooService().connect()"`

### "Business_Goals.md not found"
- Create Business_Goals.md in AI_Employee_Vault/
- Use the template from quickstart.md
- Include revenue targets and subscription list

### "Briefing file not created"
- Check CEO_Briefings/ directory exists
- Verify write permissions
- Check audit logs for errors: `AI_Employee_Vault/Audit_Logs/`

### "Subscriptions not detected"
- Ensure Business_Goals.md has subscription table
- Format: `| Service Name | Cost/Month | Category | Last Used | Status |`
- Update "Last Used" dates regularly

## Manual Execution

To generate a briefing manually (outside of scheduled time):

```python
from services.ceo_briefing_service import CEOBriefingService

briefing_service = CEOBriefingService()
briefing_file = briefing_service.generate_weekly_briefing()
print(f"Briefing generated: {briefing_file}")
```

Or use the scheduler:

```python
from scheduler.ceo_briefing_scheduler import CEOBriefingScheduler

scheduler = CEOBriefingScheduler()
scheduler.run_now()
```

## Best Practices

4. **Act on Suggestions**: Follow up on unused subscriptions and upcoming deadlines

## API Reference

### CEOBriefingService Methods

#### `generate_weekly_briefing(target_date=None)`
Generate briefing for specified week (default: current week)

**Returns:** Path to generated briefing file

#### `calculate_revenue_summary(start_date, end_date)`
Calculate revenue metrics from Odoo

**Returns:** Dict with total_revenue, invoice_count, payment_count, average_invoice_value, top_customers

#### `calculate_expense_summary(start_date, end_date)`
Calculate expense metrics from Odoo

**Returns:** Dict with total_expenses, expense_count, top_categories

#### `detect_unused_subscriptions()`
Find subscriptions not used in 30+ days

**Returns:** List of unused subscriptions with potential savings

#### `get_upcoming_deadlines(days_ahead=7)`
Get deadlines within specified days

**Returns:** List of upcoming deadlines with priority
